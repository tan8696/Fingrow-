# Fetch OSM Competitors

This skill fetches local competitors for a given latitude, longitude, and business category using the OpenStreetMap Overpass API.

## Usage
Run the python script with the lat, lon, and category:
`python fetch_data.py <lat> <lon> <category>`

Output will be a JSON string.
